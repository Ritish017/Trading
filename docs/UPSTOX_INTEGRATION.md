# Upstox V3 Market Data Integration Guide

This guide documents the architecture, configuration, security practices, and endpoints for ingesting **real live market data** from Upstox V3 into the **APEX Personal Quantitative Trading OS**.

---

## 1. Overview & Architecture

The system uses a **provider-agnostic Market Data Hub** (`MarketDataService`).

```
                    MARKET DATA HUB (service.py)
                           |
              +------------+------------+
              |            |            |
           Upstox        FYERS         Dhan
          Provider      Provider      Provider
              |
              v
        Data Normalizer (instruments.py)
              |
              v
        Candle Aggregator (candle_aggregator.py)
              |
       +------+-------+---------+
       |              |         |
     Quotes        Options    WebSocket /ws/ticks
       |              |         |
       +------+-------+---------+
              |
              v
         Quant Engine
```

> [!IMPORTANT]
> **Read-Only Analytics Scope**:
> - The Analytics Token is strictly used for read-only market data (Quotes, Candles, Option Chains, WebSocket Ticks).
> - Real-money order placement and automated trading are **disabled**.
> - Paper trading runs on an isolated in-memory paper engine (`PaperTradingEngine`).

---

## 2. Generating Your Upstox Analytics Token

1. Log into your [Upstox Developer Dashboard](https://upstox.com/developer/).
2. Create an App or navigate to your existing app credentials.
3. Generate a read-only **Analytics Token** / **API Access Token**.
4. Copy the token string.

---

## 3. Secret Management & `.env` Configuration

Paste your Analytics Token into `backend/.env`:

```env
# Provider Selection: UPSTOX, FYERS, DHAN, MOCK
ACTIVE_BROKER_PROVIDER=UPSTOX

# Strict Live Mode Flag
# Set to false (default) so disconnection reports DISCONNECTED instead of silent mock fallbacks
ALLOW_MOCK_FALLBACK=false

# ==================================================
# UPSTOX REAL MARKET DATA CONFIGURATION
# ==================================================
UPSTOX_ENABLED=true
UPSTOX_ANALYTICS_TOKEN=your_upstox_analytics_token_here
UPSTOX_BASE_URL=https://api.upstox.com
UPSTOX_WS_ENABLED=true
UPSTOX_PROVIDER_PRIORITY=upstox
```

> [!CAUTION]
> - **NEVER** commit `.env` or share your Analytics Token.
> - Secrets are loaded in Python backend runtime only and are redacted from all logs, exceptions, API responses, and frontend state.

## 5. Live vs. Simulated vs. Disconnected Modes

The React UI (`IndexTickerBar`) displays a visible status badge based on `/health/data-feed`:

| Badge | Status Code | Description |
| :--- | :--- | :--- |
| `🟢 LIVE — UPSTOX` | `CONNECTED` | Real Upstox ticks streaming via WebSocket `/ws/ticks`. Client-side tick generator is **disabled**. |
| `🟡 SIMULATED — DEV MOCK` | `SIMULATED` | Active when `ALLOW_MOCK_FALLBACK=true` or provider set to `MOCK`. Prices generated by `DevMockProvider`. |
| `🔴 DISCONNECTED` | `DISCONNECTED` | Active when live provider fails to authenticate/connect and `ALLOW_MOCK_FALLBACK=false`. Tick generator is **disabled**. |

## 6. Endpoints Reference

### Health
- `GET /health/data-feed`: Provider status, latency, active mode, and WebSocket stats.

### Quotes & Data Streams
- `GET /api/market/quote/{symbol}`: Returns normalized live quote snapshot.
- `GET /api/market/candles/{symbol}?interval=5m&count=60`: Historical OHLCV candle series.
- `GET /api/market/option-chain/{symbol}`: Underlying Option Chain, Max Pain, PCR, and Open Interest.

### Market Information
- `GET /api/market/fii-dii`: Institutional cash flows.
- `GET /api/market/open-interest/{symbol}`: Open interest metrics.
- `GET /api/market/pcr/{symbol}`: Put-Call ratio.
- `GET /api/market/max-pain/{symbol}`: Strike max pain level.
